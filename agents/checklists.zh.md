# 阶段清单（复制进你的构建进度文件）

[English](checklists.md) | 中文

只勾选你在自己主机上验证过的项。每一个未勾选的框都是不安装下一个
插件的理由。

## M0 —— 安全与遥测基线

- [ ] 隔离决策已记录（务实单用户 **或** 专用用户/容器），残余风险已写下
- [ ] `dsh --version` 和单元/服务位置已确认；备份目的地有可用空间
- [ ] 单元加固 drop-in 配置片段已应用；每条请求的指令都用 `systemctl --user show` 验证过
- [ ] 启动测试已完成：UI 能提供服务（无 cookie 时 401）、一次模型调用可用、journal 中无错误行
- [ ] DSH 遥测出站已禁用（`session-log-deepseek`、`plugin-package-inventory-deepseek`、OTel `DISABLED`），并用 `--dump-config` 预检过
- [ ] 服务 cgroup 的出站观测已生效；预期目的地已记录；对意外目的地告警
- [ ] journald 保留已有上限；摘要定时器 + 告警检查器已安装
- [ ] token/成本计量在产出本地数据；无第三方遥测导出
- [ ] 凭据存储 0600；单元环境/日志/提示词/遥测中无密钥；密钥扫描干净
- [ ] 备份脚本可运行；**恢复演练通过**（恢复到临时端口上的临时主目录）
- [ ] M0 退出条件已写入进度文件

## M0.5 —— 插件准入

- [ ] 每个候选的成熟度数据已实测（stars、月下载量、许可证、发布者、维护情况、DSH 兼容性）
- [ ] 0–3★ 单作者包已拒绝或换用自己的代码；原因已记录
- [ ] 确切版本已固定；sha512 已记录
- [ ] tarball 已扫描：无未审查的安装脚本、原生二进制、`eval`、无法解释的 `child_process`、意外网络域名、凭据访问
- [ ] 依赖已审计；无 `latest`；不自动更新
- [ ] 临时 profile 试用通过（启动 + 唯一重要的那个行为 + 出站被观测）
- [ ] 台账行齐全（版本、sha512、扫描、试用、结论、回滚）
- [ ] 人类签核已记录

## M1 —— 技术栈安装

- [ ] 会话检索按确切版本安装；索引路径 + `openAt` 显式固定
- [ ] 记忆插件固定为自托管；`HINDSIGHT_CONFIG` 为 0600 文件；记忆库仅属于你；autoSeed/autoUpdate/gitIngest 关闭
- [ ] 身份：你自己的 `SOUL.md` 在 persona 顺序 0 注入；文件缺失时为空操作；大小上限已就位
- [ ] 可选的推送/心跳以**不生效/默认关闭**安装
- [ ] 无人值守面中无 shell 自动化、无插件/凭据工具
- [ ] 活动主机启动干净；无意外出站；告警干净
- [ ] 验收：跨会话 + 重启召回；在预算内召回；记忆宕机时 fail-open；记忆库隔离；会话检索能找到旧对话；注入载荷无法触发工具；日志中无密钥；备份/恢复仍通过

## M2 —— 卫生与策略

- [ ] 记忆整理器已调度；报告仅含计数且为 0600
- [ ] 保留策略已写：什么/哪里/存多久/由什么清理
- [ ] 清除约定已记录并测试（“遗忘”实际移除了什么）
- [ ] 加密离机备份包已生成并通过解密验证
- [ ] 按界面划分的自主性策略已写（Web、心跳、推送、调度、未来渠道）
- [ ] 没有新的未审查依赖；每个组合包条目都可禁用；回滚已记录
- [ ] 进度文件已更新；提交已推送；CI 绿色
